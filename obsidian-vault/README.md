## Codex 使用总原则

1. **任务前按需读取**：先读「偏好与决策习惯」，再读「项目索引/细节」中与本任务相关的部分。
2. **每晚 10 点整理**：把当日沟通记录整理进「每日沟通日志」，更新相关项目状态。
3. **每周复盘沉淀**：每周日做一次复盘，把零散信息沉淀进项目细节，清理冗余。

详细 SOP 见 [[05-Codex操作手册/README]]。
