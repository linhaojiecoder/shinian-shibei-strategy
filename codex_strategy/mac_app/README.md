# 慢富十倍 · Codex V1 独立看板

这是 V1 原日历研究模拟的独立 Mac 看板，不是 WorkBuddy 正式数据流，也不读取或修改旧应用的状态。应用标识为 `com.linhaojie.manfu.codexv1`，私有数据位于 `~/Library/Application Support/manfu-codex-v1`。不要把模型持仓当作实盘持仓或交易指令。

首次启动使用随包的冻结不复权行情和事件快照；启动后自动更新，保持打开时每小时尝试更新，休眠唤醒后也会尝试；也可手动点击更新。关闭应用或电脑休眠期间不会更新。从新浪获取五只 ETF 不复权行情，从天天基金获取分红和拆分事件，在本地重新模拟。北京时间 16:00 前不使用当日数据，休市时显示最近共同交易日。更新需网络、`/usr/bin/python3` 和 `curl`；出现历史数据缺失或变动时停止更新并保留旧结果。数据源可能变化或不可用，仍需人工核对。

买卖假设、原日历缺陷和数据风险遵循 `docs/TAKEOVER.md` 中的 V1 说明；模型按下一共同交易日开盘价计算目标份额，真实交易不能预知最终开盘价。停牌、涨跌停、冲击成本及 QDII 溢价等未完整模拟，不保证收益，不能仅凭此进行实盘交易。

本版本为 Apple Silicon Mac 打包，应用采用临时签名，未使用 Apple 开发者证书签名或公证，其他 Mac 可能出现安全提示。不依赖公众号，也不自动交易。持仓连续天数按自然日，持仓不间断的加减仓不重置；交易或分红拆分当天不显示单只持仓当日盈亏。
