本目录与 WorkBuddy 的正式回测、App 和持仓数据隔离。不得覆盖 WorkBuddy 的策略代码、数据或报告。任何候选策略都只作为研究结果，未经用户确认不得用于实际持仓。

- `baseline_20261029.json`：完整回测结果快照，SHA-256 `5dee1315572996bf6a8822ef5dde341b6863be44837f1c68ac043c51c3b2c576`。

V1 历史假设、已知数据限制和不代表未来收益的说明见 `docs/TAKEOVER.md`。V1 原实现使用共同交易日交集及原程序日期规则，有停牌日与执行时间假设限制，不能视为实际成交记录。

## 研究约束

- 不使用决策时尚未知晓的价格、未来事件或未来选股结果；变动未来数据不能影响过去的信号、订单和账本。
- 动量等收益率信号可以使用逐日事件调整序列；成交与估值只用不复权真实价；拆分同步调整份额和成本，分红记应收并在支付日到账。
- 策略参数和候选清单先固定，再分段、滚动对比；样本外是研究评估，不保证未来表现。
- 与 V1 对比使用同一数据、交易费用、现金与交易单位规则；记录交易摩擦、调仓周敏感性与失败结果。
- 对未解决的数据差异、未模拟停牌/涨跌停/冲击成本等局限，报告必须明确披露；不把模拟收益当成可实盘承诺。
- 不得因为研究数据口径变化而修改 WorkBuddy 的 `data_version` 或生产数据。若未来明确改动生产数据口径，才按项目规则递增其 `data_version`。

## 第一轮研究记录（2026-10-29）

脚本：`python3 codex_strategy/research/run_research.py`；输出：`research/results.json` 与 `research/report.html`。基准每侧成本 0.08%，压力情景每侧费用 0.16% 加滑点 0.10%。冻结数据 2014-01-15 至 2026-10-29。

V1 年化 20.75%、最大回撤 14.11%、收益回撤比 1.47；美股目标上限 50% 为 17.00% / 14.11% / 1.20；双账户错峰为 16.83% / 15.99% / 1.05；两者结合为 13.22% / 13.88% / 0.95。三者均未改善全区间收益回撤比，不能称为 V2 胜出方案。

数据因果检查覆盖 3,104 个共同交易日；对 609 个候选信号日截断后，四套策略各自重跑，并核对截止当日信号、订单和账本。此测试未证明所有前视偏差不存在：资产池与参数可能经事后选择，历史数据可能修订，开盘成交仍是理想化假设。

2021 年以后分段此前已看过，属于探索性历史对照，不是真正盲测。后续研究先限定假设和候选数，保留失败方案；在独立新数据和真实成交限制下验证前，不升级为正式策略。
