## 五、★ 关键结论：数据口径（本次会话最重要的产出）

**根因**：westock 数据源的复权功能是坏的：
- 默认 `--fq` 不传 = 前复权 qfq（把份额拆分跳空抹平）
- `--fq nofq` = 跨拆分日口径错乱（坏的）
- `--fq bfq` = 直接报错（不支持）
- 它给不出任何口径一致的正确历史价。

**解法**：绕过 westock，用腾讯原始接口 `web.ifzq.gtimg.cn/appstock/app/kline/kline`（第 6 参数留空 = 真正不复权），拆分跳空 + 分红除息跳空都完整保留。

**已验证的事件表**（`backtest_data/events_table.json`）：

| 标的 | 除权事件 | 日期 |
|---|---|---|
| 沪深300 510300 | 现金分红约13次 | 2014起每年 |
| 纳指 513100 | **1:5 份额拆分** | 2022-01-13 |
| 标普500 513500 | **1:2 份额拆分**（无分红） | 2022-03-29 |
| 黄金 518880 | 1:0.3776 折算（上市前，不影响回测） | 2013-07-24 |
| 创业板 159915 | 通常无 | — |

**回测脚本必须正确处理的三件事**（sim_v4.py 已实现）：
1. 成交用「真正不复权价」（不碰任何复权口径）；
2. 份额拆分「锚定到拆分后首个交易日」同步调整持仓份额（拆分日停牌，不能按公告日匹配，否则份额不调整、市值凭空缩水）；
3. 区分两套分红假设（分红再投入 vs 分红现金入账）。

**独立交叉验证（买入持有收益，全部符合公开常识）**：
- 纳指 856.4%（十年8倍 ✓）
- 标普 428%（近4倍 ✓）
- 沪深300 112.2% ✓
- 创业板 103% ✓
- 黄金 28.6% ✓

## 六、给接手 AI 的提示

1. **不要再碰 qfq/hfq 复权口径**，直接读 `prices_true_nofq.json`（真正不复权价）+ `events_table.json`（事件表）。
2. App 实时引擎（engine.js）已改成腾讯原始不复权接口，与回测口径一致。
3. 实时信号（最近 20 日动量）直接用不复权价算即可——因为 20 日内不会跨越拆分/分红事件，无需后复权。
4. 当日盈亏/市值用真实价，信号用比值，两者分离，这是之前踩过的坑。
