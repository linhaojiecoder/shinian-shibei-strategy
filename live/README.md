# 十二年十倍复利策略 · 实盘跟踪系统

把回测策略（`sim_full_v3.py`）落地为「每日自动跟踪 + 双周调仓提醒」的实盘辅助工具。
**只跟踪、提醒，不自动下单** —— 下单由你手动完成（策略一个月只需操作 1~2 次，每次 5 分钟）。

## 一、文件结构

```
live/
├── signal_engine.py   # 信号引擎（与回测共用同一套规则，纯函数）
├── fetch_live.py      # 增量拉取 5 只 ETF 日线（westock CLI）
├── runner.py          # 主流程：拉数据 → 算信号 → 生成日报 → 推送
├── state.json         # 实盘状态（本金、现金、持仓、净值序列）
├── com.ashare.rebalance.tracker.plist  # macOS 定时任务
└── reports/           # 每日报告存档（markdown）
```

## 五、实盘怎么对照（关键）

回测和实盘必须用**同一套逻辑**，本项目的 `signal_engine.py` 已通过验证：
- 用回测主数据复跑，结果与 `sim_full_v3.py` 完全一致（期末 3423万 / 年化 21.12% / 回撤 -16.74% / 646 笔）。

实盘要点：
1. **双周调仓日**（日报会标注「📌 今日为双周调仓日」），按指令在**下周一开盘**手动成交。
2. **成交价**：日报里的股数用「当日收盘价」近似估算，实际成交以开盘价为准，误差可忽略（ETF 流动性好）。
3. **持仓状态**：每次成交后，手动更新 `state.json` 的 `holdings` 和 `cash`（或告诉我，我帮你写脚本同步）。这是目前唯一的「手动环节」。

## 六、数据说明

- 数据源：`westock kline`（腾讯/新浪等行情，你环境已装）。
- QDII（纳指/标普）盘中价格可能延迟，但收盘后 15:05 运行通常已更新；若发现最新日期落后 A 股，日报会体现（不会伪造数据）。
- 本地滚动数据存 `live/prices_live.json`，与回测主数据 `backtest_data/prices_full_open.json` 分离，互不污染。

## 七、常见问题

**Q：为什么有时「仅 1 只通过过滤」或「空仓」？**
A：动量>0 且日波动≤2% 是硬条件，市场普跌时可能全部被剔除，这是策略的防御机制（对应回测里的空仓/降仓期）。

**Q：能自动下单吗？**
A：国内散户拿不到券商 API，QMT 门槛高且有风险，不建议。本工具定位是「信号跟踪 + 提醒」，下单手动完成，安全且够用（策略低频）。
