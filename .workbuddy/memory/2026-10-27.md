# 2026-10-27 工作日志

## 数据口径 bug 的彻底复盘（豆包审校 + 自己实测）

### 豆包指出的、我承认的错误
1. **「qfq 高估收益是固有缺陷」——归因错误**。正确理论：分红/折算事件完整时，qfq 和 hfq 的「分红再投入总收益率」数学等价。我把它归因为 qfq 设计缺陷是错的。
2. **「hfq 是唯一可靠统一口径」——过度结论**。hfq 最新价≠真实现价（510300：hfq 1.877 vs 真实 4.179），只适合比值计算，严禁做逐笔成交模拟。
3. 遗漏：成本价口径、份额折算同步调整持仓、QDII 汇率、两套收益假设（分红再投入 vs 分红现金入账）。

### 我自己实测挖出的更严重问题（豆包没点破）
**当前 App 的「974.60%、期末 3223 万」是用混合口径 + 残缺数据算的，不可信。**

实测证据（westock kline 三口径对比 510300）：
- bfq（不复权）最新收盘 = 4.179 = 真实价 ✓
- qfq 最新收盘 = 4.179（近期无除权，qfq=真实价）
- hfq 最新收盘 = 1.877（历史分红因子压低，非真实价）

三口径区间收益（2014→2026）：
- qfq = 174.75%
- hfq = 110.66%  ← 差 64pp，理论上不该发生
- nofq = 212.49%

**结论：qfq 和 hfq 本该相等却差 64pp，说明数据源的「持续现金分红」复权因子算错了（hfq 算低了，不是 qfq 虚高）。**

### 数据源能力边界（重建的关键约束）

- 腾讯 fqkline：只给 qfq/hfq 结果，不给事件表。
- **「自己从原始价+事件表算复权因子」这条路，当前数据源能力下走不通。**

### ⚠️ 终极发现：westock 复权功能是坏的（真正根因，比豆包指出的更深）
实测 westock kline 对 513100（纳指 2022-01-13 1:5拆分）：
- **默认（不传 --fq）= `--fq qfq` = 前复权价**（拆分日跳空被抹平，01-14 收盘 1.015）。
- **`--fq hfq`** = 后复权价（01-14 收盘 5.075 = 真实价的 5 倍）。
- **`--fq nofq`** = 数据错乱（01-12 是 hfq 值 5.192，01-14 是 qfq 值 1.015，跨拆分日口径混乱）。
- **`--fq bfq`** = 直接报错 service error。

结论：**westock 对 ETF 份额折算的处理是坏的，给不出任何一份口径一致的正确历史价。**
- 之前以为「bfq 4.179 = 真实价」，其实那是 qfq 价，只因 510300 最近无除权所以恰好等于真实价，制造了假象。
- 真正的不复权历史价（含拆分跳空）在 westock 里根本拿不到。

### 数据源真实能力边界
- westock：qfq/hfq 有（但 qfq=默认，hfq 只有折算正确性存疑），无真正 bfq，nofq 是坏的，无独立事件表。
- 结论：**要做出可信的 12 年回测，必须换数据源（Wind/Choice/iFinD/东财 Choice 等专业付费源），免费源做不到。**

### ✅ 最终解决方案（2026-10-27 上午，不再依赖付费账号）
**发现腾讯原始接口能拿到真正的不复权价，绕开 westock 的坏复权。**

1. **数据源突破**：腾讯 `web.ifzq.gtimg.cn/appstock/app/kline/kline?param=<code>,day,<start>,<end>,<n>,`（第6参数留空）返回真正不复权价，拆分跳空完整保留。
   - 实测验证：513100 纳指 1:5拆分（01-12收5.192→01-14收1.015）；513500 标普1:2拆分（03-28收2.735→03-30收1.39）；510300 分红0.123元（01-16收4.859→01-19收4.738）。
   - westock 对比：默认=qfq（跳空抹平）、nofq=数据错乱、bfq=报错，全部不可用。

2. **重建数据**：`backtest_data/prices_true_nofq.json`（5只ETF，2014-01-02~2026-10-26，约3113天，真正不复权价）。
3. **事件表**：`backtest_data/events_table.json`（权威公告核实的除权事件）。
4. **回测脚本**：`sim_v4.py`，正确处理三件事：
   - 成交用不复权真实价；
   - 份额拆分「锚定到拆分后首个交易日」同步调整持仓（修复停牌日不匹配bug）；
   - 两套分红假设（现金入账 / 再投入）。
5. **最终结果**：分红现金入账 **950.71%**（期末3152万，年化20.33%，回撤-14.11%，夏普1.26）；分红再投入 912.56%。
6. **独立交叉验证通过**：买入持有收益——纳指856.4%、标普428%、沪深300 112.2%、创业板103%、黄金28.6%，与公开常识吻合。
7. **App 更新**：engine.js 改腾讯原始不复权接口；data.json 更新为诚实版；打包 v3.4.0 DMG。

### 关键教训
- westock 免费源的复权功能是坏的，尤其对 ETF 份额折算。
- 之前的 974.6% 不可信（混合口径+残缺数据+未处理拆分）。
- 腾讯原始接口（非 westock 封装）是免费拿正确不复权价的可靠途径。
