# 十年十倍复利策略 v3 · 独立验证说明

> 本包用于提交给其他 AI / 量化人员独立验证。请勿直接相信下面的结论，请用 `sim_10y_v3.py` 复现。

## 一、策略一句话描述

在 5 只 ETF 上做「动量轮动」，叠加「波动率目标」仓位管理。

## 二、完整规则（无止损 · 双周 · 20日动量 · TOP2 · 波动率目标15%）

**标的池（5 只 ETF，A股 + 美股 + 黄金）：**

| 代码 | 名称 | 类别 |
|---|---|---|
| 510300 | 沪深300 | A股 |
| 159915 | 创业板 | A股 |
| 513100 | 纳指 | 美股 QDII |
| 513500 | 标普500 | 美股 QDII |
| 518880 | 黄金 | 商品 |

**交易规则：**

1. **调仓频率**：每两周的周五（`(i//5) % 2 == 0` 的周五）收盘计算信号。
2. **选股（相对动量）**：计算每只 ETF 过去 20 日的涨跌幅，从高到低排序，取前 2 名（TOP2）。
3. **过滤**：入选标的必须同时满足「20日涨幅 > 0」且「20日波动率 ≤ 2%」。不满足则剔除，可能只买 1 只或空仓。
4. **波动率目标（仓位管理）**：
   - 用「组合自身净值」过去 20 日的日收益率算标准差，再年化（×√244）。
   - 仓位系数 `scale = min(1, 15% / 组合年化波动率)`，上限 1（不放大，只缩仓）。
   - TOP2 内部等权，实际买入金额 = 总资金 × scale ÷ 2。
5. **无止损**：持仓期间不设止损，涨跌死扛，只在下一个双周调仓日根据动量排名自然换仓。

## 三、回测口径（关键，请重点审）

- **前视偏差已消除**：信号在 T 日**收盘**计算，T+1 日**开盘价**成交。绝不使用信号日收盘价成交。
- **数据**：`prices_10y_open.json`，5 只 ETF 的日线（含开盘价/收盘价），2016-01-04 至 2026-10。
- **交易成本**：单边 `COST = 0.0008`（0.08%），买卖各收一次。
- **起始资金**：300 万，2016-01-01 起。
- **波动率目标只在双周调仓日调整**，不做每日降仓（这是拿到最优结果的关键实现细节）。

## 五、已知局限（作者主动声明，请一并审）

1. **成本估算偏乐观**：只算了 0.08% 单边，未计入 ETF 溢价/折价、滑点、冲击成本。真实年化预期大概率在 16-18%。
2. **依赖美股长牛**：回测区间恰逢美股大牛市，21% 年化里相当部分来自纳指/标普的 beta，而非纯 alpha。
3. **震荡市表现差**：2026 年 YTD -1.78%，暴露了 20 日动量在快速轮动震荡市追涨杀跌的软肋。
4. **无单日止损**：极端单日暴跌时是硬扛的，靠波动率目标提前降仓而非事后止损。

## 六、复现方法

```bash
python3 sim_10y_v3.py
```

依赖：仅标准库（json / os / statistics / datetime）。输出 `backtest_data/sim_10y_v3.json`，含 nav_series（逐日净值）、hold_series（逐日持仓）、trades（逐笔交易）、summary（汇总指标）。

## 七、请重点验证的问题

1. 前视偏差是否真的消除？（信号日收盘算、次日开盘成交）
2. 波动率目标是否只用「组合自身净值」而非等权篮子？
3. 交易成本口径是否一致？
4. 换一个时间起点（如 2018、2020 起）结果是否稳健？是否过拟合？
5. 逐笔交易是否有异常（比如买入/卖出价格是否落在当日高低价区间内）？
